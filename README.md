# KaoYan-408-Notes

27 考研备考资料与个人笔记：数学二 + 计算机 408（数据结构 / 计算机组成原理 / 操作系统 / 计算机网络）。

## 关于

笔者原是一名 27 考研人，3-9 月积极备考，积累下了大量笔记，后临时保研，无缘考场。遂将这份笔记整理开源，希望能帮到正在备考路上的你。

## 内容结构

```
.
├── 01.数学
│   ├── 01.高等数学        # 按章节整理的笔记
│   └── 02.线性代数        # 按专题整理的笔记
└── 02.专业课
    ├── 01.数据结构        # 笔记、综合题、错题集
    ├── 02.计算机组成原理   # 笔记、综合题、错题集
    ├── 03.操作系统        # 笔记、综合题
    └── 04.计算机网络      # 笔记、综合题
```

笔记使用 Obsidian 编写，各目录下的 `pic/` 文件夹为笔记引用的图片，请勿单独删除。

## 使用说明

- 笔记为个人备考记录，详略与视角因人而异，建议搭配教材、课程与真题一起使用。
- 如发现笔记中的错误，欢迎提交 [Issue](https://github.com/huahuo156/KaoYan-408-Notes/issues) 指正；不过由于时间等原因，不一定会更改，还请谅解。
