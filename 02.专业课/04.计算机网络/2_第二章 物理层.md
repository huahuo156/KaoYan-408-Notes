# 第二章 物理层
## 通信基础
### 基本概念
#### 数据、信号、码元
**数据**：信息的载体，即用于传送信息的实体
**信号**：数据的电气或电磁表现，是数据在传输过程中的真实形式

数据和信号均可分为 **模拟和数字**：<mark style="background:#fff88f">模拟信号的取值是连续的；数字信号的取值是离散的</mark>

**码元**：通常用一个固定时长的信号波形表示一个 k 进制符号，该波形称为 码元/ k 进制 码元，而该时长称为 码元宽度/信号周期；每个码元能承载的信息量与其所表示的信号状态数量直接相关，即<mark style="background:#40a9ff">若一个信号周期内可能出现 k 种波形，那么表示该码元携带 $\log_2k$ 位比特</mark>

#### 信源、信道、信宿
**信源**：产生与发送数据的源头
**信宿**：接收数据的终点
**信道**：信号的传输介质；特别的，一条双向通信的线路包括一个发送信道和一个接收信道
- 根据传输信号的形式可以划分为 传送模拟信号的模拟信道 和 传送数字信号的数字信道
- 根据数据传输方式分类：
	- **串行传输**：逐比特按序依次传输，适用于<mark style="background:#fff88f">长距离传输</mark>
	- **并行传输**：若干比特通过多个信道同时传输，适用于<mark style="background:#fff88f">短距离传输，常用于计算机内部</mark>
- 根据交互方式分类：
	- **单向通信**：只有一个方向的通信而没有反向的交互；只需一个信道
	- **半双工**：<mark style="background:#fff88f">通信双方都可发送或接收信息，但任何一方都不能同时接收和发送</mark>；同一个信道分时双向传输，或者两个单向信道
	- **全双工**：通信双方可同时发送和接收信息；需要两个独立信道

#### 速率、波特、带宽
**速率**是指数据传输速率，表示单位时间内传输的数据量，表示方式：
- 码元传输速率/波特率/调制速率：表示数字通信系统每秒传输的**码元数**，单位是 波特/Baud；码元速率与进制无关
- 信息传输速率/比特率：表示数字通信系统每秒传输的**比特数**，单位是 b/s

>[!attention] 辨析：波特与比特
>波特与比特是两个不同的概念，两者存在如下的数量关系：<mark style="background:#40a9ff">若一个码元携带 n 比特的信息量，则波特率 M Baud 对应的比特率为 M * n b/s</mark>

**带宽**：
- 在模拟通信中，表示信道所能传输信号的频率范围，即**最高频率与最低频率之差**，单位为 赫兹/Hz
- 在数字通信或计算机网络中，表示通信线路所能传输数据的能力，即**最大数据传输速率**，单位为 b/s

### 信道的极限容量
#### 奈奎斯特定理/奈氏准则
<mark style="background:#40a9ff">奈氏准则：在理想信道(无噪声、带宽有限)中，为避免码间串扰，极限码元传输速率为 2W 波特，其中 W 是指信道的频率带宽(Hz)</mark>；
若用 V 表示每个码元的**离散电平数量**(非比特数)，则有$$理想低通信道的极限数据传输速率 = 2W\log_2V\;\quad (单位\quad b/s)$$
如下结论：
1. 在任何通道中，<mark style="background:#fff88f">码元传输速率存在上限</mark>
2. <mark style="background:#fff88f">信道带宽越大，其传输码元的能力越强</mark>
3. <mark style="background:#fff88f">奈氏准则仅限制码元传输速率，并未限制每个码元所能承载的信息量</mark>，因此信息传输速率仍可采用多元调制来提升

#### 香农定理
<mark style="background:#40a9ff">香农定理给出了 带宽受限且有高斯噪声干扰的信道 的极限数据传输速率</mark>。香农定理认为 $$信道的极限数据传输速率 = W\log_2(1+S/N) \quad (单位\quad b/s)$$
其中 W 为信道的频率带宽，S 为信号的平均功率，N 为噪声功率。S/N 为信噪比，即信号的平均功率与噪声的平均功率之比

>[!caution] 信噪比的表示方式
>1. 无单位记法：信噪比 = S/N
>2. 分贝记法：信噪比 = $10\log_{10}(S/N)$ (单位为 dB)

如下结论：
1. <mark style="background:#fff88f">信道带宽 或 信噪比 越大</mark>，信息的极限传输速率越高
2. 对于给定的带宽和信噪比，信息传输速率的上限是确定的，即<mark style="background:#fff88f">每个码元所能携带的比特数是有限的</mark>
3. ~~香农定理给出的是理论极限，实际比该值要低不少~~

>[!important] 影响信道传输速率的因素
>1. 信道极限传输速率：若同时给出信噪比、码元与比特数之间的关系，<mark style="background:#fff88f">信道的极限传输速率受到 香农定理和奈氏准则 的共同限制，取两者中的较小者</mark>
>2. 实际计算：**信道带宽**、**信噪比**、**调制速率**(即波特率)

### 编码与调制
为数据传输，无论模拟的还是数字的数据最终都要转换成信号
将数据转换为数字信号的过程称为 编码，将数据转换为模拟信号的过程称为 调制

#### 数字数据**编码**为数字信号
1. **归零编码** / RZ
	1. 规则：<mark style="background:#fff88f">高电平表示 1，低电平表示 0(<font color="#ff0000">或相反</font>)，每个码元中间都会跳变回 0(“归零”)</mark>
	2. 是否自同步：<mark style="background:#d3f8b6">是</mark>，接收方可以利用上述跳变来调整自身的时钟基准，实现自同步
	3. 是否浪费带宽：<mark style="background:#fff88f">是</mark>
	4. 抗干扰能力：<mark style="background:#d3f8b6">弱</mark>
2. **非归零编码** / NRZ
	1. 规则：<mark style="background:#fff88f">与 RZ 编码的区别是 不进行归零，整个周期都可以用来传输数据</mark>
	2. 是否自同步：<mark style="background:#d3f8b6">否，需要额外时钟线来实现自同步</mark>
	3. 是否浪费带宽：<mark style="background:#fff88f">否，编码效率最高</mark>
	4. 抗干扰能力：<mark style="background:#d3f8b6">弱</mark>
3. **反向非归零编码** / NRZI
	1. 规则：<mark style="background:#fff88f">以码元起始处是否有跳变来表示数据：无跳变表示 1，有跳变表示 0</mark>
	2. 是否自同步：<mark style="background:#d3f8b6">是，需增添冗余位来实现</mark>，跳变本身可用于辅助实现时钟恢复
	3. 是否浪费带宽：<mark style="background:#fff88f">不太浪费</mark>
	4. 抗干扰能力：<mark style="background:#d3f8b6">弱</mark>
4. **曼彻斯特编码**(传统以太网采用的编码方式)
	1. 规则：<mark style="background:#fff88f">每个码元中间都有一次电平跳变，该跳变同时承担 <mark style="background:#40a9ff">时钟同步</mark> 与 <mark style="background:#40a9ff">数据表示</mark> 功能</mark>；常用下降沿表示 1，上升沿表示 0，或采用反向的约定
	2. 是否自同步：<mark style="background:#d3f8b6">是</mark>，主要用于数据通信的原因
	3. 是否浪费带宽：<mark style="background:#fff88f">是</mark>
	4. 抗干扰能力：<mark style="background:#d3f8b6">强</mark>
5. **差分曼彻斯特编码**
	1. 规则：<mark style="background:#fff88f">与曼彻斯特编码不同的是，<mark style="background:#40a9ff">码元中间的跳变仅用于时钟同步</mark>，而不表示数据。数据由码元起始处是否有跳变决定：无跳变表示 1，有跳变表示 0</mark>
	2. 是否自同步：<mark style="background:#d3f8b6">是</mark>
	3. 是否浪费带宽：<mark style="background:#fff88f">是</mark>
	4. 抗干扰能力：<mark style="background:#d3f8b6">更强</mark>

#### 模拟数据编码为数字信号
采用 PCM(脉冲编码调制)

#### 数字数据调制为模拟信号
1. **振幅键控**/ASK：改变振幅
2. **频移键控**/FSK：改变频率
3. **相移键控**/PSK：改变相位
4. **正交幅度调制**/QAM：
	1. 在载波频率相同的前提下，通过调制振幅和相位，形成复合信号
	2. <mark style="background:#40a9ff">假设波特率为 B，采用 m 个相位，每个相位有 n 个振幅，则该 QAM 的数据传输速率 R 为 $R=B\log_2(m\times n)$ (单位 b/s)</mark>

## 传输介质
### 双绞线、同轴电缆、光纤、无线传输介质
#### 双绞线
1. 适用范围：<mark style="background:#fff88f">局域网与传统电话网</mark>，即可用于<mark style="background:#d3f8b6">模拟传输</mark>，也可用于<mark style="background:#d3f8b6">数字传输</mark>
2. 结构：<mark style="background:#fff88f">绞合结构</mark>可有效减少相邻导线间的电磁干扰；<mark style="background:#fff88f">屏蔽层</mark>可进一步提升抗干扰能力

#### 同轴电缆
1. 适用范围：<mark style="background:#fff88f">早期局域网</mark>，<mark style="background:#fff88f">有线电视系统</mark>
2. 结构：
	1. <mark style="background:#d3f8b6">外导体屏蔽层</mark>具有抗电磁干扰能力，适合较高速率的数据传输；
	2. <mark style="background:#d3f8b6">绝缘层</mark>
	3. <mark style="background:#d3f8b6">内导体</mark>用于传输信号，越粗电阻越小，传输距离越长

#### 光纤
1. 通信原理：当光从高折射率介质射向低折射率介质时，入射角大于临界角，将会发生<mark style="background:#fff88f">全反射</mark>，使光线在纤芯与包层界面反复反射而向前传播
2. 分类：
	1. 多模光纤：<mark style="background:#fff88f">允许多条不同角度入射的光线</mark>在同一根光纤中传输；损耗大，适合<mark style="background:#fff88f">短距离传输</mark>
	2. 单模光纤：光纤直径减小到接近光波波长时，<mark style="background:#fff88f">仅允许单一模式的光传播，几乎无反射；适用于远距离传输</mark>
3. 优点：
	1. 通信容量极大
	2. 传输损耗少
	3. 抗雷电和电磁干扰性强
	4. 无串音干扰，保密性强，不易被窃听和截取数据
	5. 体积小，重量轻

#### 无线传播介质
1. 无线电波：具有较强的穿透能力，传播距离远，被广泛用于移动通信和 WLAN。但指向性弱
2. 微波、红外线、激光：具有强指向性

>[!note] 无线传播介质传输能力与波的频率、波长的关系
>1. 频率越高，数据传输能力越强
>2. 波长越短，信号指向性越强，趋于直线传播；越长，“穿墙”能力越强

#### 物理层接口的特性
1. 机械特性
2. 电气特性：规定各线路应遵循的**电压范围**、传输速率、距离限制
3. 功能特性：定义每条线路上**<mark style="background:#fff88f">特定</mark>电平所表示的意义**
4. 过程特性

## 物理层设备
“无脑”广播接收到的消息

### 中继器
1. 功能：<mark style="background:#40a9ff">整形、放大并转发信号</mark>，以消除信号经过一长段电缆后产生的失真和衰减
2. 工作原理：<mark style="background:#40a9ff">信号放大</mark>(并非简单放大衰减信号)
3. 接口网络连接：<mark style="background:#40a9ff">两端属于同一个局域网内的不同子网；不隔离冲突域</mark>
4. 工作模式：<mark style="background:#fff88f">半双工</mark>
5. 中继器不能无限串联，“5-4-3 规则”：4 个中继器连接 5 个网段中仅有 3 个网段可以连接设备

### 集线器
1. 功能：<mark style="background:#40a9ff">多端口的中继器</mark>，整形、放大并 <mark style="background:#ff4d4f">广播</mark> 传播信号；<mark style="background:#40a9ff">属于共享式设备(连接的设备平分带宽)</mark>
2. 接口网络连接：<mark style="background:#40a9ff">不分割冲突域，反而合并冲突域</mark>
3. 网络拓扑结构：<mark style="background:#40a9ff">物理上是星形网络，逻辑上是总线型网络</mark>
4. 工作模式：<mark style="background:#fff88f">半双工</mark>
5. 集线器不能无限串联

>[!important] 中继器与集线器可以连接的网络 
>中继器与集线器 均工作在 **物理层**，无法对 **帧** 实现解封与重新封装(即无法实现 **协议的转换**)，因此无法连接不同链路层协议的网段；但可以**连接 不同介质的局域网**，只要它们具有相同的协议；也**无法连接 速度不匹配的网络**
