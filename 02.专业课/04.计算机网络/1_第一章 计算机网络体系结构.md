# 第一章 计算机网络体系结构
## 计算机网络概述
### ~~计算机网络的概念~~
计算机网络由 **若干结点** 和 连接该些结点的**链路** 组成
- 结点可以是 计算机、集线器、交换机、路由器 等

**多个网络还可以通过*路由器*互联**，构成覆盖范围更广的计算机网络，称之为 “互连网”

>换言之，网络将多台计算机连接在一起，而互连网则将多个路由器连接在一起

>[!attention] 辨析：internet/互连网 与 Internet/互联网
>1. **互连网**：**通用名词**，泛指由多个计算机网络互连而成的网络，该些网络之间<mark style="background:#40a9ff">可以采用 任意通信协议进行通信</mark>
>2. **互联网**：**专用名词**，特指当前全球最大、开放的、由众多网络和路由器互连而成的特定计算机网络，<mark style="background:#40a9ff">必须采用 TCP/IP 协议族 进行通信</mark>

互联网用户最后通过 互联网服务提供商/ISP 接入互联网

### ~~计算机网络的组成~~
1. 从组成部分看：
	1. **硬件**：主要包括 主机、通信链路、交换设备
	2. **软件**：主要包括 **实现资源共享的系统软件** 与 **便于用户使用的应用工具**
	3. <mark style="background:#40a9ff">协议</mark>：计算机网络的**核心**，规定了数据在网络中传输时必须遵循的规则
2. 从工作方式看：
	1. **边缘部分**：由所有连接到互联网、**供用户直接使用的主机**组成，用于<mark style="background:#fff88f">通信和资源共享</mark>
	2. **核心部分**：由大量网络及互连该些网络的路由器组成，<mark style="background:#fff88f">为边缘部分提供连通性与交换服务</mark>

### 交换技术
>[!important] 网络采用的交换技术
>**分组交换** 时延更小、更灵活，尤其适合 **突发式(高频、少量)** 数据通信
>关键部件：**路由器**，采用**存储转发技术**

#### 电路交换
1. 过程：**建立连接**(占用通信资源)、**传输数据**(持续占用通信资源)、**释放连接**(归还通信资源)
2. 特点：数据传输前，<mark style="background:#fff88f">必须建立一条专用的端到端物理链路</mark>；在通信过程中，<mark style="background:#fff88f">该通信链路被双方独占</mark>
3. 适用于：低频次、连续且大量的数据传输
4. 优点：<mark style="background:#fff88f">通信时延小</mark>；<mark style="background:#fff88f">有序传输</mark>；<mark style="background:#fff88f">没有冲突</mark>；<mark style="background:#fff88f">时效性强</mark>
5. 缺点：<mark style="background:#fff88f">建立连接时间长</mark>；<mark style="background:#fff88f">线路利用率低</mark>；<mark style="background:#fff88f">灵活性差</mark>；<mark style="background:#fff88f">难以实现差错控制</mark>

#### 报文交换
1. 过程：报文分装、<mark style="background:#40a9ff">存储转发</mark>
2. 特点：<mark style="background:#40a9ff">整个报文传送到相邻结点，被完整接收并存储后，结点根据转发表将其转发到下一跳，逐跳转发，直至达到目的地</mark>；<mark style="background:#d3f8b6">每个报文可独立选择通往目的地的路径</mark>
3. 优点：
	1. 无建立和释放连接的时延
	2. 线路分配灵活
	3. <mark style="background:#fff88f">线路利用率高</mark>
	4. <mark style="background:#fff88f">支持差错控制</mark>
4. 缺点：
	1. <mark style="background:#fff88f">存储转发时延高</mark>：结点<mark style="background:#fff88f">必须完整接收整个报文</mark>后，才能开始转发
	2. <mark style="background:#fff88f">缓存开销大</mark>：报文没有大小限制
	3. <mark style="background:#fff88f">错误处理低效</mark>：报文越长，出错概率越大、重传成本越高

#### 分组交换
1. 思想：<mark style="background:#40a9ff">采用存储转发技术</mark>，在发送前，由源主机<mark style="background:#40a9ff">将较长报文划分成较小的等长数据段，并提添加必要的控制信息组成的首部</mark>
2. 优点：
	1. 继承报文转发的优点
	2. <mark style="background:#fff88f">便于存储管理，转发开销小</mark>：分组大小固定
	3. <mark style="background:#fff88f">传输效率高</mark>：分组可逐个发送，实现流水线技术
	4. 降低出错概率与重转代价
3. 缺点：
	1. 存在存储转发时延
	2. <mark style="background:#fff88f">需要传输额外的信息量</mark>：每个分组前增添的必要的控制信息
	3. <mark style="background:#fff88f">分组可能失序、丢失、重复</mark>

### 计算机网络的分类
1. 按分布范围分类：
	1. **广域网**：用于长距离通信、构建互联网的骨架部分；范围：**几千米至数千千米**
	2. ~~城域网~~
	3. **局域网**：将主机通过高速链路互连；范围：**几十米到几千米**；<mark style="background:#40a9ff">局域网采用广播技术、而广域网采用交换技术</mark>
	4. ~~个人区域网~~
2. 按传播技术分类
	1. **广播式网络**：
		1. 所有计算机共享一个公共通信信道；
		2. 工作方式：<mark style="background:#fff88f">某计算机发送报文分组时，其余计算机均可“收听”到该分组，并通过检查目的地址决定是否接收</mark>
	2. **点对点网络**：每条物理链路连接一对计算机
3. 按拓扑结构分类
	1. **总线形网络**：
		1. 组织形式：<mark style="background:#fff88f">使用单根传输线连接所有计算机</mark>
		2. 传播技术：<mark style="background:#40a9ff">广播式传播</mark>
		3. 硬件：<mark style="background:#40a9ff">集线器</mark>
		4. 优点：简单易建，增删结点方便
		5. 缺点：<mark style="background:#40a9ff">通信效率低、一处故障影响全网</mark>
	2. **星形网络**
		1. 组织方式：各终端或计算机<mark style="background:#fff88f">通过 独立线路 连接到中央设备</mark>(交换机或路由器)
		2. 传播技术：<mark style="background:#40a9ff">点对点传播</mark>
		3. 硬件：<mark style="background:#40a9ff">交换机、路由器</mark>
		4. 优点：便于集中控制与管理、<mark style="background:#40a9ff">不存在总线争用问题</mark>
		5. 缺点：成本高、<mark style="background:#40a9ff">中央设备对故障敏感</mark>
	3. **环形网络**
		1. 组织形式：<mark style="background:#fff88f">所有计算设备连接成一个<mark style="background:#d3f8b6">闭合回路</mark>，信号沿着回路<mark style="background:#d3f8b6">单向传输</mark></mark>
		2. 传播方式：<mark style="background:#40a9ff">广播式传播</mark>；令牌环局域网
	4. **网状网络**
		1. 组织方式：<mark style="background:#fff88f">每个结点至少有两条路径与其他结点相连</mark>，广泛应用于 **广域网**
		2. 传播技术：<mark style="background:#40a9ff">点对点传播</mark>

### 性能指标
1. **速率**：在数字信道上传送数据的速率
2. **带宽**：表示网络通信线路能传送数据的能力，指<mark style="background:#fff88f">数字信道所能支持的最高数据传输速率</mark>；<mark style="background:#fff88f">具体链路的带宽取决于<mark style="background:#40a9ff">瓶颈链路</mark>的带宽</mark>
3. **吞吐量**：指单位时间内通过某个网络的<mark style="background:#fff88f">实际数据量(上行、下行数据量之和)</mark>
4. **时延**：指数据从网络的一端传送到另一端所需的总时间
	1. *发送时延*：
		1. 结点将分组的所有比特推入链路所需的时间
		2. <mark style="background:#fff88f">发送时延 = 分组长度 / 发送速率</mark>
	2. *传播时延*：
		1. 电磁波在信道中传输一定距离所需的时间
		2. <mark style="background:#fff88f">传播时延 = 信道长度 / 电磁波在信道上的传输速率</mark>
	3. ~~处理时延~~：分组在交换结点为存储转发而进行必要处理所需花费的时间
	4. ~~排队时延~~：分组在路由器的输入队列或输出队列中等待或转发锁花费的时间
5. **时延带宽积**：
	1. 指发送端发送的第一个比特即将到达接收端时，发送端已发出的比特数，即已发出但尚未到达接收端的最大比特数
	2. <mark style="background:#fff88f">时延带宽积 = 传播时延 * 信道带宽</mark>
6. **往返时延**/RTT：指发送端发出一个短分组，到收到接收端返回的确认信号所经历的总时间
7. **信道利用率**：
	1. 指信道有数据通过的时间占总时间的比例
	2. <mark style="background:#fff88f">信道利用率 = 有数据通过的时间 / (有数据通过的时间 + 无数据通过的时间)</mark>

## 计算机网络体系
### 计算机网络分层结构
体系结构是抽象的，而实现是具体的

分层原则：
1. 每层之间实现一种相对独立的功能
2. 各层之间的接口清晰、简洁
3. 各层功能的低难以独立于具体实现方法
4. 保持下层对上层的独立性，上层单向调用下层提供的服务

若干概念：
1. 对等层：不同机器上的同一层
2. 对等体：同一层的实体
3. 协议数据单元/PDU：对等层之间传送的数据单元；由服务数据单元和协议控制单元组成
4. 服务数据单元/SDU：相邻层之间交换的数据单元
5. 协议控制单元/PCI：用于控制协议操作的信息

> <mark style="background:#fff88f">PDU,SDU,PCI 之间有这样的关系：n-SDU + n-PCI = n-PDU =(n-1)-PDU</mark>

### 协议、服务、接口的概念
#### 协议
协议 是<mark style="background:#40a9ff">对等体</mark>之间通信的规则合集，是<mark style="background:#40a9ff">水平的</mark>。<mark style="background:#40a9ff">不同对等体之间不存在协议</mark>

组成：
1. **语法**：规定数据与控制信息的<mark style="background:#fff88f">格式</mark>
2. **语义**：规定需要发出何种<mark style="background:#fff88f">控制信息</mark>、完成何种<mark style="background:#fff88f">动作</mark>以及做出何种<mark style="background:#fff88f">应答</mark>
3. **同步/时序**：规定执行各操作的<mark style="background:#fff88f">条件</mark>以及事件发生的<mark style="background:#fff88f">先后顺序</mark>

#### 接口
同一结点内相邻两层实体交换信息的逻辑接口称为 服务访问点
<mark style="background:#40a9ff">每层只能与紧邻的上下层定义接口，不允许跨层定义接口</mark>

#### 服务
服务是指下层为紧邻的上层提供的功能调用，是<mark style="background:#40a9ff">垂直的</mark>

服务与协议的区别：
1. <mark style="background:#d3f8b6">下层协议对上层是透明的</mark>；而本层协议的正确实现才能保证向上层提供服务
2. 协议是水平的，服务是垂直的
3. <mark style="background:#d3f8b6">只有被上层感知的并调用的功能才称为 服务</mark>

>[!caution]
>1. 网络协议三要素中的**语法定义**的是**对等实体之间**交换的**协议数据单元(PDU)的结构与格式**
>2. **服务原语**是相邻层之间通过服务访问点交互的指令，属于层间接口定义，由服务定义

### OSI 参考模型与 TCP/IP 模型

#### OSI 参考模型
1. **物理层**
	1. 传输单位：**比特**
	2. 作用：在物理介质上为数据端设备透明地传输原始比特流
	3. 实现功能：
		1. 规定了接口的<mark style="background:#d3f8b6">机械特性和电气特性</mark>
		2. 规定了通信链路上的<mark style="background:#d3f8b6">编码意义与电气特征</mark>
		3. 注意：传输所用的 **物理介质** 不属于物理层的范畴，属于**数据链路层**
2. **数据链路层**
	1. 传输单位：**帧**
	2. 作用：将物理层提供的可能出现差错的物理连接，<mark style="background:#fff88f">改造为逻辑上无差错的数据链路</mark>；<mark style="background:#fff88f">结点到结点的通信</mark>
	3. 实现功能
		1. **差错控制**
		2. **流量控制**
3. **网络层**
	1. 传输单位：**数据报/分组**
	2. 作用：将分组从源主机传送到目的主机，<mark style="background:#fff88f">为不同主机提供通信服务</mark>；<mark style="background:#fff88f">主机到主机的通信</mark>
	3. 实现功能：
		1. **路由选择**
		2. **拥塞控制**
		3. **差错控制**
		4. **流量控制**
		5. ~~网际互连~~
		6. 有连接的虚电路服务、无连接的数据报服务
4. **传输层/运输层**
	1. 数据单位：**报文段**
	2. 作用：负责不同主机中<mark style="background:#fff88f">进程之间的端到端通信</mark>
	3. 实现功能
		1. **连接管理**
		2. **可靠传输**(<mark style="background:#40a9ff">OSI 模型仅提供面向连接的<mark style="background:#ff4d4f">可靠传输</mark></mark>)
		3. **流量控制**
		4. **差错控制**
		5. **复用与分用**
			1. **复用**：指多个应用进程可以同时使用传输层的服务
			2. **分用**：指传输层能将接收到的数据准确交付给对应的上层进程
5. ~~会话层~~
	1. 作用：管理不同主机上进程之间的会话
	2. 实现功能：**断点传输**(即使会话中断也可以后续恢复会话)
6. ~~表示层~~
	1. 作用：解决异构系统间信息表示不一致的问题，即**格式转换**
7. ~~应用层~~
	1. 作用：最高层，作为用户与网络的接口

#### TCP/IP 模型
**事实上的国际标准**

1. **网络接口层**(对应 OSI 模型中的 *物理层和数据链路层*)
	1. 作用：从主机或结点接收 IP 分组，并将其发送到指定的物理网络上
	2. 并未规定该层的具体功能或协议细节
2. **网际层**(对应 OSI 模型中的 *网络层*)
	1. 传输单位：<mark style="background:#fff88f">IP 数据报</mark>
	2. 作用：核心部分，负责<mark style="background:#fff88f">将分组发往任意网络</mark>，并<mark style="background:#fff88f">为分组独立选择路由</mark>，但不保证分组有序到达，分组的有序性和可靠性由高层负责，且<mark style="background:#fff88f">不提供差错控制</mark>；<mark style="background:#d3f8b6">提供无连接、不可靠的服务</mark>
	3. 核心协议：\[互联网核心协议\]<mark style="background:#ff4d4f">IP 协议</mark>,\[其他辅助协议\]地址解析协议/ARP,网际控制报文协议/ICMP
3. **传输层**(对应 OSI 模型中的 *传输层*)
	1. 作用：旨在实现发送端与接收端主机上<mark style="background:#d3f8b6">对等进程之间的逻辑通信</mark>
	2. 核心协议：
		1. <mark style="background:#ff4d4f">TCP</mark>：
			1. 特点：<mark style="background:#40a9ff">面向连接，可靠传输</mark>
			2. 传输单位：<mark style="background:#40a9ff">报文段</mark>
		2. <mark style="background:#ff4d4f">UDP</mark>：
			1. 特点：<mark style="background:#40a9ff">无连接，不保证可靠</mark>，“尽最大努力交付”
			2. 传输单位：<mark style="background:#40a9ff">用户数据报</mark>
4. **应用层**(对应 OSI 模型中的 *会话层、表示层、应用层*)
	1. 协议：包含所有高层协议，包括 文件传输协议/FTP,域名解析服务/DNS,超文本传输协议/HTTP
