# 第一章 计算机系统概述
## 计算机硬件
### 冯诺依曼机 的基本思想
1. 采用 <mark style="background:#fff88f">“存储程序”</mark> 的工作方式：将编制好的程序和初始数据预先存入主存储器，实现了计算机的自动化。
2. <mark style="background:#fff88f">硬件系统由五大部分组成</mark>：<u>输入设备、输出设备</u>(统称为 I/O 设备)、<mark style="background:#ff4d4f">运算器(中心地位)</mark>、控制器、存储器(包括 主存\[对应“运行内存”\] 与 辅存\[俗称“内存”\])。
	- <u>运算器、控制器、存储器</u> 共同组成“主机”
3. <mark style="background:#fff88f">指令与数据</mark>以相同的形式<mark style="background:#fff88f">存放在存储器中</mark>，仅凭形式无法区分。
4. <mark style="background:#fff88f">指令与数据均以二进制编码表示</mark>。
5. <mark style="background:#fff88f">指令由 操作码(指明操作类型) 和 地址码(指明操作数的地址) 组成</mark>。

### 现代计算机 构成
现代计算机将 <u>运算器、控制器与各类寄存器</u> 高度集成，形成一块称为 <u>中央处理器</u>(CPU) 的芯片。

![[pic/计算机系统概述--现代计算机的结构.png#pic-center|现代计算机结构|603]]
![[pic/计算机系统概述--现代计算机的结构(简化).png#pic-center|现代计算机结构(简化)|624]]

完整的计算机硬件系统主要包括：
1. 中央处理器：计算机系统中主要负责指令执行的核心部件
	- 传统组成部分：运算器 + 控制器
	- 现代计算机：
		- 数据通路(包括 算数逻辑单元[ALU，负责完成所有算数与逻辑运算] 和 通用寄存器[为ALU提供操作数并暂存运算结果]) 
		- 控制单元(负责协调整个 CPU 的工作，读指令->译码->生成控制信号等)
2. 存储器：通常分为 内存与外存 (<mark style="background:#ff4d4f">现代计算机以存储器为中心地位</mark>)
	- 传统组成部分：内存仅指 主存，且主存作为核心的工作存储器，用于存放待执行的程序和数据
	- 现代计算机：内存由 主存和高速缓存Cache 组成
3. 外部设备和设备控制器
4. 总线：是计算机中用于在各个部分之间传输数据的公共通路。

#### 主存储器
![[pic/计算机系统概述--主存储器.png#pic-center|主存储器|231]]

主存储器由 <mark style="background:#fff88f">地址寄存器MAR(存放地址)、数据寄存器MDR(存放数据)、存储体(存储指令与数据)</mark>
###### 存储体
![[pic/计算机系统概述--主存储器--存储体.png#pic-center|存储体|199]]
1. 存储体由存储单元构成
2. 存储单元：每个存储单元存放的二进制代码
3. 存储字：存储单元中二进制代码的组合
4. <mark style="background:#fff88f">存储字长：存储单元中二进制代码的位数</mark>

>[!tip] 存储体与寄存器MAR/MDR之间关系
> 1.地址寄存器 MAR 位数反映存储体中存储单元的容量
> 2.数据寄存器 MDR 位数等于存储体的存储字长

#### 运算器
![[pic/计算机系统概述--运算器.png#pic-center|运算器|188]]
运算器由 <mark style="background:#fff88f">逻辑算数单元(ALU) 与 寄存器</mark>(包括 累加寄存器 ACC、乘商寄存器 MQ、通用寄存器 X 等) 组成
- 逻辑算数单元(ALU)：用于实现所有的算数运算与逻辑运算

#### 控制器
![[pic/计算机系统概述--控制器.png#pic-center|控制器|260]]
控制器由 <mark style="background:#fff88f">控制单元(CU)、指令寄存器(IR)、程序计数器(PC)</mark> 组成
- 控制单元(CU)：分析指令，给出控制信号
- 指令寄存器(IR)：存放当前执行的指令
- 程序计数器(PC)：存放下一条指令地址，有自动增 "1" 功能\[仍需要 CPU 发出控制信号\]

>[!tip] PC 的指向
>若<mark style="background:#40a9ff">顺序指令</mark>，则 PC 自动指向当前指令的下一条指令。
>若当前指令为<mark style="background:#40a9ff">跳转指令</mark>，则 PC 不再指向当前指向的下一条指令：
>- 条件跳转指令：
>	- 若跳转条件成立，则指向跳转后的目标指令；
>	- 若跳转条件不成立，则顺序指向下一条指令；
>- 无条件跳转指令，则一定指向跳转后的目标指令

### 计算机工作过程
![[pic/计算机系统概述--计算机工作过程.png#pic-center|计算机工作过程|538]]
图中部分符号/表达式简单说明：

|     符号 / 表达式      |      含义       |
| :---------------: | :-----------: |
|         M         |   主存中某存储单元    |
| ACC、MQ、X、MAR、MDR… |     相应寄存器     |
|      M(MAR)       |   取存储单元中的数据   |
|      (ACC)…       |  取相应寄存器中的数据   |
|        指令         | 由操作码和地址码两部分组成 |
|      OP(IR)       |     取操作码      |
|      Ad(IR)       |     取地址码      |

> [!non-important]- 计算机工作过程--以“取数”指令的执行为例
> （从主存中指定地址处取数）
> 
> 1. $( \text{PC} ) \rightarrow \text{MAR}$
> 2. $\text{M}( \text{MAR} ) \rightarrow \text{MDR}$
> 3. $( \text{MDR} ) \rightarrow \text{IR}$
> （**取指令结束**） 
> 4. $( \text{PC} ) + 1 \rightarrow \text{PC}$
> 5. $\text{OP}( \text{IR} ) \rightarrow \text{CU}$
> （**分析指令结束**）
> <mark style="background:#fff88f">↑↑必经步骤--“取指”过程↑↑</mark>
> <mark style="background:#fff88f">↓↓变化步骤--指令实际执行过程↓↓</mark>
> 6. $\text{Ad}( \text{IR} ) \rightarrow \text{MAR}$
> 7. $\text{M}( \text{MAR} ) \rightarrow \text{MDR}$
> 8. $( \text{MDR} ) \rightarrow \text{ACC}$
> （**执行指令结束**）


>[!note] CPU 区分数据与指令
>指令执行的过程可大致分为 “取指”过程 与 指令实际执行过程，故 <mark style="background:#fff88f">CPU 可以通过指令阶段的不同来区分指令与数据</mark>
>且 <mark style="background:#fff88f">CPU 内部的 <mark style="background:#40a9ff">控制器</mark> 来分辨数据与指令</mark>

## 计算机软件
- **两类软件**
    - **系统软件**：管理计算机系统的硬件资源，向上层应用程序提供服务
    - **应用软件**：按应用场景需要编制成的各种程序，直接为用户提供服务

- **三个级别的语言**
    - 高级语言、汇编语言(仍然是机器级语言)、<mark style="background:#fff88f">机器语言(计算机<mark style="background:#ff4d4f">唯一</mark>能直接识别和执行的语言)</mark>
    - **编译程序(编译器)**——将高级语言<mark style="background:#fff88f">一次全部翻译</mark>为汇编语言，或直接翻译为机器语言
    - **汇编程序(汇编器)**——将汇编语言翻译成机器语言
    - **解释程序(解释器)**——高级语言翻译为机器语言（<mark style="background:#fff88f">翻译一句执行一句，执行效率较低</mark>）
>[!tip] 编译程序与解释程序适用场景
> 1.编译程序适合执行时间短、运行频率高的程序，<mark style="background:#40a9ff">目标代码执行效率高</mark>，但<mark style="background:#40a9ff">可移植性较差</mark>
> 2.解释程序适合执行时间短、运行频率低的程序，<mark style="background:#40a9ff">目标代码执行效率低</mark>，但<mark style="background:#40a9ff">可移植性较好</mark>

- <mark style="background:#fff88f">软件和硬件的逻辑功能等价性</mark>
    - <mark style="background:#40a9ff">同一个功能，既可以用硬件实现(效率高、成本高)，也可以用软件实现(效率低、成本低)</mark>

- <mark style="background:#fff88f">指令集体系结构(ISA)</mark>：完整定义了软件可直接调用的硬件功能，不涉及硬件的实现细节；是指软件能够感知到的部分
    - $ISA$定义一台计算机可以支持哪些指令，以及每条指令的作用是什么、每条指令的用法是什么。
    - <mark style="background:#40a9ff">同一个 ISA 可由不同微体系结构实现，软件无需修改即可兼容</mark>
    - ISA 是对指令系统的一种规定或结构规范，具体实现的组织称为 **微体系结构**；微体系结构是软件不可感知的部分；相同的 ISA 可能具有不同的 微体系结构

## 计算机的性能指标
### 存储器的容量
- 地址寄存器 MAR 的位数 $n_1$ 反映存储体存储容量的大小
- 数据寄存器 MDR 的位数 $n_2$ 等于存储体的存储字长
存储器的存储容量为 $n = n_2\times2^{n_1}(bit)$ 

### 与 CPU 相关的性能指标
- **时钟周期**：$CPU$中最小的时间单位，每个动作至少要$1$个时钟周期
- **主频（时钟频率）**：$=\frac{1}{\text{时钟周期}}$，单位：$Hz$
- **CPI**：<mark style="background:#40a9ff">执行一条指令所需的时钟周期数</mark>，常取平均场景下的 CPI

>[!warning] CPI 以及 运行时间的影响因素
> 时钟频率并不会影响 CPI，而时钟频率会影响 最终的 CPU 执行时间
> 而影响 CPI 的因素有：
> 1. **指令集**
> 2. **计算机组织与微架构**(如cache命中率、流水线技术、数据通路)
> 3. **程序编写的优劣以及编译优化**

- **CPU执行时间**：
  - 运行一个程序所花费的时间
  - $=\text{时钟周期数}\cdot \text{时钟周期}=\frac{\text{时钟周期数}}{\text{主频}}=\color{Blue}\frac{\text{指令条数} \times \text{平均}CPI}{\text{主频}}$
- **IPS**：每秒执行多少条指令 $= \frac{\text{主频}}{\text{平均} CPI}$
- **FLOPS**：每秒执行多少次<u>浮点运算</u>，主要用于衡量超大型计算机的运算速度

### 其他性能指标
- **数据通路带宽**：数据总线一次所能并行传送信息的位数（各硬件部件通过数据总线传输数据）
- **吞吐量**：指系统在单位时间内处理请求的数量

>[!note] 
><mark style="background:#40a9ff">吞吐量的大小</mark>，取决于信息能多快地输入内存，CPU 能多快地取出指令，数据能多快地从内存中取出或存入，都<mark style="background:#40a9ff">关系到主存</mark>，故吞吐量与主存存储周期密切相关

- **响应时间**：指从用户向计算机发送一个请求，到系统对该请求做出响应并获得它所需要的结果的等待时间
- **基准程序**：用来测量计算机处理速度的一种实用程序，以便于被测量的计算机性能可以与运行相同程序的其它计算机性能进行比较。(相当于跑分软件；<mark style="background:#fff88f">但并不意味着跑分越高，计算机性能越高</mark>)

>[!note]- **常用数量单位**
> 1. 描述存储容量、文件大小时：$K=2^{10}$，$M=2^{20}$，$G=2^{30}$，$T=2^{40}$
> 2. 描述频率、速率时：$K=10^3$，$M=10^6$，$G=10^9$，$T=10^{12}$
